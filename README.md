# Kampuzz

**Your Kampuzz, Your Steezz**

Android APK downloads for Kampuzz. This repository holds only the installable apps, not the source code.

## Which APK to install

Open the [latest release](https://github.com/OriginalSolution/kampuzz-releases/releases/latest) on your phone and download one of these:

- **arm64-v8a** — most phones from about 2017 onward
- **armeabi-v7a** — older phones

If you're not sure, try the arm64-v8a build first. If Android says the app isn't compatible, use the armeabi-v7a build.

Android may show an unknown-app or Play Protect prompt. That is normal for sideloaded installs — tap Install anyway.

Each release lists the version, version code, and SHA-256 checksums.
